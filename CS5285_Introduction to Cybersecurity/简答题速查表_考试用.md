### 模板2：CBC vs CTR

**题目**：one bit error / block lost / update, which mode better?

**答案**：
```
[CTR/CBC] is better.
- CBC: [2 blocks / missing 1 + garbled 1 / re-encrypt all]
- CTR: [1 block / all wrong / only modify one]
```

**查表**：
| 关键词 | 更好的 | CBC | CTR |
|--------|--------|-----|-----|
| one bit error | CTR | 2 blocks | 1 block |
| block lost | CBC | missing 1 + garbled 1 | all wrong |
| update | CTR | re-encrypt all | modify one |

---

### 模板3：CTR做MAC

**题目**：CTR as MAC, why not secure?

**答案**：
```
Not secure because:
1. Known-plaintext attack: KS = C ⊕ P
2. Forge: C' = C ⊕ P ⊕ P'
3. MAC unchanged (independent blocks)
```

---

### 模板4：MAC不可否认

**题目**：Can MAC provide non-repudiation?

**答案**：
```
No.
- MAC uses symmetric key (shared)
- Both parties can generate MAC
- Cannot prove who sent
```

### 模板5：RSA签名长度

**题目**：Largest message for RSA signature?

**答案**：
```
- Message must be < n
- Hash first, then sign (hash-then-sign)
```

### 模板6：证明文件相同

**题目**：Prove two files are the same?

**答案**：
```
- Calculate hash of both files
- Compare hash values
- If identical → same file
```

## 三、公式速查

| 名称 | 公式 |
|------|------|
| CBC加密 | Cᵢ = E(Pᵢ ⊕ Cᵢ₋₁) |
| CBC解密 | Pᵢ = D(Cᵢ) ⊕ Cᵢ₋₁ |
| CTR加密 | Cᵢ = Pᵢ ⊕ E(IV+i) |
| CTR解密 | Pᵢ = Cᵢ ⊕ E(IV+i) |
| RSA签名 | S = M^d mod n |
| ElGamal加密 | (c₁,c₂) = (g^r, M·y^r) |
| DH密钥 | K = B^x = A^y |
| 生日攻击 | 2^(n/2) |
| DES暴力 | 2^55 |
| 3DES密钥 | 2^111 |
