## 二、知识体系（原知识地图）

### 2.1 安全基础（PPT1）

**CIA 三要素**：
- **Confidentiality**（机密性）：防止未授权泄露 → 加密（AES/DES）
- **Integrity**（完整性）：防止未授权修改 → MAC/数字签名（HMAC/RSA）
- **Availability**（可用性）：防止拒绝服务 → 冗余/备份

**认证类型**：
- **Entity Authentication**：验证"你是谁"（登录协议）
- **Origin Authentication**：验证"数据来自谁"（MAC/签名）
- **Access Control**：验证"你能做什么"（授权模型）

**不可否认性**：
- **Non-repudiation of origin**：发送方不能否认发送 → 数字签名
- **Non-repudiation of delivery**：接收方不能否认收到 → 签名+解密密钥

**分析框架（威胁→服务→机制）**：

| 威胁 | 服务 | 机制/算法 |
|------|------|-----------|
| 数据泄露 | Confidentiality | Encryption (AES/DES) |
| 数据篡改 | Integrity | MAC/Digital Signature (HMAC/RSA) |
| 否认发送 | Non-repudiation | Digital Signature (RSA/DSA) |
| 冒充身份 | Authentication | Authentication Protocol |
| 未授权使用 | Access Control | Access Control Model |

**应用场景**：
- 网上银行：认证（防冒充）+ 机密性（防泄露支付数据）+ 完整性（防修改交易）
- 软件下载：完整性/来源认证（数字签名）+ 不可否认性（防否认收到）

### 2.2 对称加密（PPT2-4）

**基础密码**：
- **Shift Cipher**：Ek(X) = (X + k) mod n
- **One-Time Pad**：完美保密，但密钥分发困难
- **Stream Cipher**：生成密钥流，XOR 明文

**分组密码模式（重点）**：

| 模式 | 公式 | 特点 |
|------|------|------|
| CBC | Cᵢ = Ek(Pᵢ ⊕ Cᵢ₋₁)，C₀=IV | 链式依赖，1错2块，块丢失丢1乱1 |
| CTR | Cᵢ = Pᵢ ⊕ Ek(Counterᵢ) | 独立加密，1错1位，块丢失后续全错 |

**3DES 与 DESX**：
- **3DES**：112位密钥，暴力破解 2^111 次
- **DESX**：K1(128)+K2(56)+K3(128)=312位总密钥
- **3AES vs AES-256**：AES-256更快（14轮 vs 30轮）

### 2.3 数论工具（PPT6）

**核心算法**：
- **欧几里得算法**：y = qx + r 迭代，求 GCD
- **扩展欧几里得**：回代 ax + by = 1，求逆元
- **快速幂**：指数转二进制，迭代平方+乘
- **欧拉函数**：φ(p)=p-1, φ(pq)=φ(p)φ(q)
- **费马小定理**：a^(p-1) ≡ 1 (mod p)

### 2.4 公钥加密（PPT5）

**ElGamal**：
- 密钥生成：y = g^x mod p
- 加密：(c₁, c₂) = (g^r mod p, M·y^r mod p)
- 解密：M = c₂ · (c₁^x)^-1 mod p

**Diffie-Hellman**：
- Alice: A = g^x mod p → 发送 A
- Bob: B = g^y mod p → 发送 B
- 共享密钥：K = B^x = A^y = g^xy mod p
- **中间人攻击防护**：添加数字签名 Sign(A, B, timestamp)

**RSA**：
- 密钥生成：n = pq, φ(n) = (p-1)(q-1), ed ≡ 1 (mod φ(n))
- 加密：C = M^e mod n
- 签名：S = M^d mod n
- 验证：M = S^e mod n

### 2.5 完整性（PPT5/Ex5）

**Hash 函数**：
- 性质：单向性、抗碰撞
- h(x) = g^x mod p：不满足单向性（可用费马小定理找碰撞）
- 填充方案：补0不安全，应补"1000..."

**碰撞攻击**：
- 生日攻击：128位Hash，找碰撞需约 2^64 次计算

**CBC-MAC 伪造**：
- 已知：M' = M₀||M₁ 的 MAC T'，M'' = M₂||M₃||M₄ 的 MAC T''
- 构造：M''' = M₀||M₁||X||M₃||M₄
- 伪造 MAC：X = M₂ ⊕ T'，让中间状态匹配
