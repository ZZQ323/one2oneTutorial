## 1. 安全基础（PPT1）：管"什么是安全"

**核心问题**：要保护什么？怎么保护？

### 1a. CIA 三要素（P2）
- **Confidentiality**（机密性）：防止未授权泄露 → 加密（AES/DES）
- **Integrity**（完整性）：防止未授权修改 → MAC/数字签名（HMAC/RSA）
- **Availability**（可用性）：防止拒绝服务 → 冗余/备份

### 1b. 认证与访问控制（P3）
- **Entity Authentication**：验证"你是谁"（登录协议）
- **Origin Authentication**：验证"数据来自谁"（MAC/签名）
- **Access Control**：验证"你能做什么"（授权模型）

### 1c. 不可否认性（P3）
- **Non-repudiation of origin**：发送方不能否认发送 → 数字签名
- **Non-repudiation of delivery**：接收方不能否认收到 → 签名+解密密钥

### 1d. 分析框架（⚠️薄弱点）
**威胁→服务→机制** 三层对应：
| 威胁 | 服务 | 机制/算法 |
|------|------|-----------|
| 数据泄露 | Confidentiality | Encryption (AES/DES) |
| 数据篡改 | Integrity | MAC/Digital Signature (HMAC/RSA) |
| 否认发送 | Non-repudiation | Digital Signature (RSA/DSA) |
| 冒充身份 | Authentication | Authentication Protocol |
| 未授权使用 | Access Control | Access Control Model |

**应用场景**：
- 网上银行：认证（防冒充）+ 机密性（防泄露支付数据）+ 完整性（防修改交易）
- 软件下载：完整性/来源认证（数字签名）+ 不可否认性（防否认收到）

## 2. 对称加密（PPT2-4）：管"怎么加密数据"

**核心问题**：同一把钥匙，怎么安全地加密和解密？

### 2a. 基础密码（PPT2/Ex2）
- **Shift Cipher**（P4）：Ek(X) = (X + k) mod n
  - 4-bit 输入，k=3，n=16：A=0000→D=0011
- **Substitution Cipher**：字母表替换
- **One-Time Pad**：完美保密，但密钥分发困难
- **Stream Cipher**：生成密钥流，XOR 明文（快、无需可逆、需完整性检查）

### 2b. 分组密码模式（PPT4/ps1）⚠️重点
- **CBC 模式**（P5）：Cᵢ = Ek(Pᵢ ⊕ Cᵢ₋₁)，C₀=IV
  - 优点：相同明文块加密结果不同（依赖前文）
  - 错误传播：1 比特错影响 2 个明文块（当前块乱+下一块对应位翻转）
  - 块丢失：当前块丢+下一块乱
- **CTR 模式**（P6）：Cᵢ = Pᵢ ⊕ Ek(Counterᵢ)
  - 优点：可并行、无错误传播、无需 padding
  - 计数器递增，不能重复使用

### 2c. 3DES 与 DESX（Ex3）
- **3DES**（P9）：C = DES_K1(DES^-K2(DES_K1(M)))
  - 112 位密钥（56+56），暴力破解平均 2^111 次
- **DESX**（P10）：C = K3 ⊕ DES(K2, M ⊕ K1)
  - AESX-192：K1(128)+K2(192)+K3(128)=448 位总密钥空间
- **3AES vs AES-256**（P11）：
  - 3AES（2×128 位密钥）= 256 位密钥空间但 30 轮
  - AES-256 = 256 位密钥 14 轮
  - AES-256 更快（轮数少）

## 3. 数论工具（PPT6）：管"怎么算大数"

**核心问题**：大数模运算怎么算？（工具，不是考点本身）

### 3a. 欧几里得算法（P12）
- **求 GCD**：y = qx + r 迭代直到 r=1
  - gcd(x,y)=1 时存在逆元
- **扩展欧几里得**（P13）：回代求解 ax + by = 1
  - x 即为 a 模 b 的逆元

### 3b. 快速幂模运算（P14）
- **Square-and-Multiply**：指数转二进制，从高位到低位迭代
  - 例：11^15 mod 13 → 15=8+4+2+1 → 11^8 × 11^4 × 11^2 × 11^1

### 3c. 欧拉函数与费马小定理（P15/P16）
- **欧拉函数 φ(n)**：
  - φ(p) = p-1（素数）
  - φ(p₁p₂) = φ(p₁)φ(p₂)
  - φ(n) = n(1-1/p₁)(1-1/p₂)...
- **费马小定理**：a^(p-1) ≡ 1 (mod p)，p 是素数
  - 用于简化大指数：a^191 mod 47 → 191 = 46×4 + 7 → (a^46)^4 × a^7 ≡ 1^4 × a^7

## 4. 公钥加密（PPT5）：管"怎么安全交换密钥"

**核心问题**：两把不同的钥匙，怎么加密、签名、交换密钥？

### 4a. ElGamal 加密（P17）
- **密钥生成**：y = g^x mod p（x 私钥，y 公钥）
- **加密**：(c₁, c₂) = (g^r mod p, M·y^r mod p)
- **解密**：M = c₂ · (c₁^x)^-1 mod p
- **安全服务**：机密性 + 认证（结合签名）+ 完整性 + 不可否认性

### 4b. Diffie-Hellman 密钥交换（P18）
- **交换过程**：
  - Alice: A = g^x mod p → 发送 A
  - Bob: B = g^y mod p → 发送 B
  - 共享密钥：K = B^x = A^y = g^xy mod p
- **中间人攻击**（P19）：攻击者替换 A 和 B，分别与双方建立密钥
- **防护**：添加数字签名 Sign(A, B, timestamp)
  - 需要 CA 证书或预共享公钥
  - 时间戳防重放

### 4c. RSA 加密与签名（P20）
- **密钥生成**：n = pq, φ(n) = (p-1)(q-1), ed ≡ 1 (mod φ(n))
- **加密**：C = M^e mod n
- **签名**：S = M^d mod n
- **验证**：M = S^e mod n

## 5. 完整性（PPT5/Ex5）：管"怎么验证数据没被改"

**核心问题**：怎么确保数据完整、来源可信？

### 5a. Hash 函数（P21/P22）
- **性质**：单向性、抗碰撞
- **h(x) = g^x mod p**：不满足单向性（可用费马小定理找碰撞）
  - 例：p=19, g=7, x=1 → h(1) = 7^1 = 7
  - 碰撞：y = x + k(p-1) = 1 + 18 = 19 → h(19) = 7^19 ≡ 7^1 (mod 19)
- **填充方案**（P22）：
  - 128 位分块，消息+填充到 16 字符倍数
  - 填充必须总是应用（即使已满）
  - 不安全填充：可构造碰撞（在填充区插入数据）

### 5b. 碰撞攻击（P23）
- **生日攻击**：128 位 Hash，找碰撞需约 2^64 次计算

### 5c. CBC-MAC 伪造（P24）
- **已知**：M' = M₀||M₁ 的 MAC T'，M'' = M₂||M₃||M₄ 的 MAC T''
- **构造**：M''' = M₀||M₁||X||M₃||M₄
- **伪造 MAC**：利用 CBC 模式的链式特性，选择 X 使得中间状态匹配

## 7. 分析题框架

**框架**：威胁 → 服务 → 机制

**步骤**：
1. 识别威胁（什么可能被攻击？）
2. 确定被破坏的服务（CIA 哪个？）
3. 推荐机制（用什么算法/协议防护？）

**例题**：
- 网上银行密码被窃听 → Confidentiality 被破坏 → 用加密（TLS/AES）
- 软件被篡改 → Integrity 被破坏 → 用数字签名
- 用户否认收到软件 → Non-repudiation → 用签名+解密密钥

## 8. 去年考题分析（MT2025）

### 8.1 考题结构
- **Q1（13分）**：OTP(hex)、Stream Cipher已知明文攻击、Shift Cipher频率分析
- **Q2（15分）**：CBC vs CTR 对比（解密方程、错误传播、块丢失、数据库效率、MAC安全性）
- **Q3（16分）**：RSA签名计算、离散对数问题(DLP)
- **Q4（6分）**：MAC不可否认性、RSA签名长度限制、Hash验证文件
- **Q5（5分）**：判断题（完美保密、Hash性质、DES复杂度、生日攻击）

### 8.2 新增考点（P25-P41）

| 考点 | 公式/要点 | 来源 |
|------|-----------|------|
| OTP异或加密(hex) | C = P ⊕ K（按位XOR），学号后4位作密钥 | MT2025 Q1(a) |
| Stream Cipher已知明文攻击 | C' = C ⊕ P_old ⊕ P_new | MT2025 Q1(b) |
| Shift Cipher频率分析 | 最频繁字母→对应'e'，推算密钥 | MT2025 Q1(c) |
| CBC vs CTR错误传播 | CBC:1错2块；CTR:1错1位 | MT2025 Q2(b) |
| CBC vs CTR块丢失 | CBC:丢1乱1；CTR:后续全乱 | MT2025 Q2(c) |
| CBC vs CTR数据库效率 | CTR更优：更新只需改对应块 | MT2025 Q2(d) |
| CTR做MAC不安全 | 已知明文→算出密钥流→可伪造 | MT2025 Q2(e) |
| RSA签名计算(求d) | n=pq→φ(n)→ed≡1→求d→S=m^d | MT2025 Q3(a) |
| 离散对数问题(DLP) | 已知a=b^c mod n，求c | MT2025 Q3(b) |
| DLP破解ElGamal | 从y=g^x求x→可解密/伪造 | MT2025 Q3(b) |
| MAC不能不可否认 | 对称密钥双方共享→无法证明发送者 | MT2025 Q4(a) |
| RSA签名长度限制 | 消息不能大于n；大消息→先Hash再签名 | MT2025 Q4(b) |
| Hash验证文件相同 | 计算两文件Hash/MAC，相同则文件相同 | MT2025 Q4(c) |
| 完美保密vs计算安全 | 完美：无限算力破不了；计算：实际破不了 | MT2025 Q5(b) |
| Hash性质区分 | 单向性(pre-image)vs抗碰撞；Bitcoin=单向性 | MT2025 Q5(c) |
| DES暴力破解 | 56位密钥→平均2^55次 | MT2025 Q5(d) |
| 生日攻击 | n位Hash→碰撞2^(n/2)；SHA-1→2^80 | MT2025 Q5(e) |

### 8.3 去年考题重点总结

**计算题高频**：
1. OTP/Stream Cipher XOR计算（hex）
2. RSA签名（求d，计算S=m^d mod n）
3. Shift Cipher频率分析

**分析题高频**：
1. CBC vs CTR 对比（错误传播、块丢失、效率、MAC安全性）
2. 离散对数问题与ElGamal安全性
3. MAC vs 数字签名（不可否认性）

**判断题陷阱**：
- 完美保密 ≠ 计算安全
- Hash单向性 ≠ 抗碰撞
- DES密钥56位（不是64位）
- 生日攻击 2^(n/2)
