## Question 1 (13 marks)

### (a) (4 marks)
Use the last 4 digits of your student number (60209978 → **9978**) as a one-time pad to encrypt the message **52B5** (show calculations). Provide answer as hexadecimal sequence.

**Note**: 0x indicates hexadecimal. Message 1A2B = binary 0001 1010 0010 1011

### (b) (6 marks)
You intercept ciphertext **0xA1B3C5**, and you know part of the plaintext **0x??4D??** (? indicates unknown position). Show how you would modify the ciphertext so that the known plaintext part will decrypt to **0xD4** instead of **0x4D**. Show all calculations, and give the full modified ciphertext.

### (c) (3 marks)
Given ciphertext **"GGTKG"**, try to decrypt it using a Shift Cipher.

## Question 2 (15 marks)

The encryption equations for two block cipher modes are provided:

**Mode 1 (CBC)**:
- C₀ = E_K(P₀ ⊕ IV)
- C₁ = E_K(P₁ ⊕ C₀)
- C₂ = E_K(P₂ ⊕ C₁)

**Mode 2 (CTR)**:
- C₀ = P₀ ⊕ E_K(IV)
- C₁ = P₁ ⊕ E_K(IV+1)
- C₂ = P₂ ⊕ E_K(IV+2)

### (a) (4 marks)
Give the decryption equations of both modes for P₀, P₁, P₂. Clearly show if you use block cipher as Encrypt (ENC) or Decrypt (DEC).

### (b) (3 marks)
During transmission one bit of C₀ is changed. In which mode is the error propagation less? Briefly explain the error propagation in each mode.

### (c) (3 marks)
During transmission the entire block C₀ is lost (the receiver does not know it has been lost and thinks C₁ is C₀, C₂ is C₁, etc.) but all other ciphertext blocks are received. In which mode is the error propagation less? Briefly explain the error propagation in each mode.

### (d) (2 marks)
You need to encrypt customer records that are then stored on a server. You regularly need to access and update these records. Which of these modes would be more efficient to use? Briefly explain why.

### (e) (3 marks)
A company implements a MAC using Mode 2 (CTR). Explain why this would not be a secure MAC implementation (how would you change a plaintext block and still have a valid MAC value?).
