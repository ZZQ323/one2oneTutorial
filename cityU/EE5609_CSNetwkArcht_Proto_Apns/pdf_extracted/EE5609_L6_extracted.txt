TCP header format
• Sequence Number (SN):
• Each TCP connection will start with an SN called Initial Sequence Number 
(ISN)
• The position of each data byte in the byte stream is labelled from ISN+1
• SN indicates the position of the 1st byte in each segment
•
Acknowledgement Number (AN):
• AN of the next data byte expected from sender
• Implies all bytes up to AN-1 have been received correctly
•
Window Size (W):
• The number of bytes counted from AN that the receiver is ready to 
accept

retransmits that segment?
34

Time from sending data
to receiving its ACK.
SRTT (smoothed)
A smoothed estimate from
multiple RTT samples.
RTO (waiting limit)
How long TCP waits before
a timeout retransmission.
Too short: unnecessary retransmissions
Too long: slow recovery from segment loss
Solution: Measure Round Trip Time (RTT) and compute smoothed RTT 
(SRTT). The Retransmission TimeOut (RTO) is then derived from SRTT.
