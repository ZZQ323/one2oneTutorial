From DEX to Machine Code
(APP Installation & First launch)
•DEX bytecode is translated to machine code on device(varies by chips)
E.g., Snapdragon8Gen5(驍龍) ,  Dimensity9500 (天璣)
•DalvikVM(Android4.4andprior)
■Installation Translationispure“Just-In-Time” compilation(JIT)
•ART VM (Android 5 API 21 and after)
■Installation Translation is “Ahead-Of-Time” (AOT)compilation +JIT compilation
•In Android 5 and 6, all Dex-code are translated during the installation of the app
on the device. 
•Sincefrom Android 7 (Nougat), only minimal Dex code gets translated during 
installation. The rest will get translated at runtime.

----- page 45 -----
45
The machine code keep changing
•Dexbytecodetomachinecode translation is continuous, not just during 
Appinstallation or the first timelaunch.
•The system collects user behavior as a profile and uses it to recompile code 
in the background for optimal performance. (Profile-Guided Compilation, 
offline)
•Even during app usage, frequently executed (“hot”) code may be 
dynamically translated in real-time to boost performance. (Just-In-Time/JIT 
Compilation, runtime)
•Performance is not the only consideration (Battery Status, Memory Usage 
status, etc.,)

Introduction to Android Kotlin Development
•Kotlin is a statically typed JVM based language developed by JetBain.
•If you are a Java developer, then you can easily learn Kotlin.

boilerplate codes.

Android app development.
•You can still use Java as an official language for app development.
•For Android Studio 3.0 or above, Kotlin is packed with Android Studio.
In this course, we will still provide Java code for most examples to reduce learning 
burden (as you may use Java in many other coursesand projects). 
But you are welcome to use Kotlin in this course.

----- page 53 -----
Advantage of Kotlin over Java (1)
•Kotlin is more concise than Java
■You can make solutions in fewer lines of reliable codes with very less bugs and crashes. 
By using Kotlin you can avoid many boilerplate codes from your app.
•Kotlin is Null Safe
■One of the main challenge of Android Java developers is to manage and fix the null 
pointer exception. If you use Kotlin, you are almost free from null pointer exception. 
Kotlin codes are null safe.
•Kotlin improve performance
■Kotlin help you to improve your app performance because Kotlin uses fewer lines of 
codes than Java for your app business logic.

----- page 54 -----
Advantage of Kotlin over Java (2)
•Kotlin is more expressive
■You can write more logics with less code.
•Kotlin uses extension functions
■You can extend any class with new features even if you don’t have access to the source code.
•Kotlin is interoperable
■You can use any libraries and codes written in Java, because Kotlin is designed in such a way that 
it is highly interoperable with Java.
•Kotlin is a functional language
■Kotlin is an object-oriented programming language with many functional programming concepts 
such as lambda expression to solve problems in easier way.

App development requirements
Essentially, we don't have any specific constraints regarding the app 
you propose to develop, as long as:
1.The app isfunctionally complete in terms of its core functionalities. 
E.g., A chatting app must be able to facilitate chats, a game app must 
be playable, and a tool app must be able to complete its basic tasks.
2.It showcases your own thoughts in certain aspects, such as UI/UX 
design or the story behind the app etc. Just ensure it is not merely a 
copy or simulation of some existing apps, as that would be pointless.
3.The workload is adequate for the team size, ensuring everyone 
collaborates effectively. 
4.Basic tool apps like To-Do List, Calendar, Billing, Timer, Notes etc.,are 
not welcomed unless they include distinctive and genuinely 
interesting features.
