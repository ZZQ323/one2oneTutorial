Android Toast Notifications
•Toast is an Android UI component that is used to show 
message or notification that does not require any user 
action.
•It is independent to the activity in which it is being shown 
and disappears automatically after the set duration.
// When clicked, show a toast with the TextView text 
Toast.makeText(getApplicationContext(), ((TextView) 
view).getText(),
Toast.LENGTH_SHORT).show();

BMI App in Landscape Mode
•In the AVD, press “Ctl+F11” keys can switch the device to landscape display mode:
•In the landscape mode, the button of “See BMI Report Now” cannot be displayed on the screen.
•Similarly problem also appears on the Report Activity UI.
•If the AVD cannot display the rotated view, you can enable Auto-rotate screen in Setting->Display of
