Android Networking
•Android support several HTTP client packages for network 
connections:
■java.net: Provides basic network APIs (core classes include Socket, URL, 
URLConnection), serving as the foundation for Java/Android network 
communication.
■java.net.HttpURLConnection:  Dedicated to handling HTTP/HTTPS 
requests
■OKHttp:Well package basic HTTP operations, designed for general 
Java/Kotlin networking. 
■Retrofit:  Therecommended choice for Android; an upper-layer 
framework built on OkHttp, specifically designed for Android networking48

----- page 6 -----
Connecting to the Network
1.Declare Permissions:
■Declare Permissions to use the network in AndroidManifest.xml
2.Make Separate Threads:
■Network operations involve unpredictable delays. Hence, it’s 
recommended that you always perform network operations on 
separate threads other than UI thread (main thread).
■Another method is to use Async Task class or Coroutines
3.Connect and Download Data:
■A client app can use Socket or HttpURLConnection classes to send 
HTTP requests and receive.

Manage Multithreading in Android
The Main Thread
•Each app has a single foreground thread and known as
Main Thread or UI Thread
•All visual elements are on the main thread
■Don’t block the main thread!
■Don’t access the user interface from other threads!
