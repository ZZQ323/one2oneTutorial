#### File3 ⚠️ 需要你在 Windows 上完成
**原因：** 6位密码的搜索空间为 62^6 ≈ 568亿，在这个环境中无法在合理时间内完成。

**你需要做的：**

1. **下载 hashcat**
   - 访问：https://hashcat.net/hashcat/
   - 下载 Windows 版本（.7z 或 .zip）
   - 解压到任意目录（如 `C:\hashcat\`）

2. **准备文件**
   - 将 `file3.txt` 复制到 hashcat 目录

3. **运行 hashcat**
   ```cmd
   cd C:\hashcat
   
   # 查看可用的处理器
   hashcat -I
   
   # 使用 CPU 破解（推荐先用这个测试）
   hashcat -m 20 -a 3 -D 1 file3.txt -1 ?l?u?d ?1?1?1?1?1?1
   
   # 如果你有独立显卡，可以使用 GPU 加速（更快）
   hashcat -m 20 -a 3 -D 2 file3.txt -1 ?l?u?d ?1?1?1?1?1?1
   ```

4. **监控进度**
   - 运行过程中按 `s` 键查看进度
   - 预计时间：
     - GPU：30分钟-2小时
     - CPU：5-10小时

5. **截图**
   - 破解完成后，截图显示结果
   - 截图应包含：
     - 所有6个密码
     - 运行时间统计
     - 你的命令

6. **记录结果**
   - 将6个密码填入 `PS2_Solutions.md` 的 Q6(b) 部分
   - 记录实际运行时间，用于回答 Q6(c) 和 Q6(d)

### Q7: PGP 邮件 ⚠️ 需要你手动完成

**步骤：**

1. **安装 Thunderbird**
   - 下载：https://www.thunderbird.net/
   - 安装版本 78 或更高

2. **配置邮箱**
   - 设置你的邮箱账号（CityU 邮箱或个人邮箱）

3. **创建 PGP 密钥对**
   - Tools → OpenPGP Key Manager
   - Add Key → Create a new OpenPGP key
   - 输入你的姓名和邮箱
   - 设置强密码
   - 导出公钥备份

4. **导入课程公钥**
   - 下载 `tsgexercise_cert.asc`（已在作业文件夹中）
   - Tools → OpenPGP Key Manager
   - File → Import Public Key(s) from File
   - 选择 `tsgexercise_cert.asc`

5. **发送加密邮件**
   - 新建邮件
   - 收件人：tsgexercise@gmail.com
   - 主题：`CS5285 PS2 EncryptedMail XXXXXXXX`（替换为你的8位学号）
   - 正文：任意内容
   - 附件：你的公钥文件
   - 启用加密和签名（点击锁和铅笔图标）
   - 发送

6. **截图**
   - 截图显示：
     - 邮件主题（包含学号）
