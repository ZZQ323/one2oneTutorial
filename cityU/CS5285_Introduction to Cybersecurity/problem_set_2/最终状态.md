- 这个环境无法在合理时间内完成
- 作业要求使用 hashcat 并提供截图

**你需要做的：**

```cmd
# 1. 下载 hashcat
# 访问：https://hashcat.net/hashcat/
# 下载 Windows 版本并解压

# 2. 准备文件
# 将 file3.txt 复制到 hashcat 目录

# 3. 运行破解
cd C:\path\to\hashcat
hashcat -I                          # 查看可用处理器
hashcat -m 20 -a 3 -D 1 file3.txt -1 ?l?u?d ?1?1?1?1?1?1

# 如果有独立显卡（推荐）：
hashcat -m 20 -a 3 -D 2 file3.txt -1 ?l?u?d ?1?1?1?1?1?1

# 4. 监控进度
# 按 's' 键查看状态
```
